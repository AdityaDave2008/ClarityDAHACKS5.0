# Demo and Devpost checklist

Submission deadline: **October 17, 2026, 2:00 PM PDT**. Check [official announcements and schedule](https://dahacks5.devpost.com/details/dates) for changes.

## Submission owner checklist

- [ ] Assign a submission owner and confirm every team member is registered and eligible.
- [ ] Add project name, problem, solution, key features, and impact.
- [ ] Link a publicly accessible source repository and verify judge access while logged out.
- [ ] Include screenshots and technologies used.
- [ ] List every teammate and their contributions.
- [ ] Credit existing code, assets, libraries, APIs, and tools.
- [ ] Record a demo video, recommended length 2–3 minutes.
- [ ] Include a live demo if available and verify all links.
- [ ] Submit before the deadline and verify submission confirmation.

## Suggested demo

1. State the user and problem.
2. Show the core user journey working.
3. Explain the implementation and what was built during the hackathon.
4. Close with impact and limitations.

Prepare non-sensitive seed data and a recorded fallback. Do not display credentials or personal data. Projects must be substantially developed during the event. See [official requirements](https://dahacks5.devpost.com/) and [rules](https://dahacks5.devpost.com/rules). Confirm conflicting eligibility/team-size wording with organizers.
